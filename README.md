# AMA

Practical implementations for AMA (Advanced Machine Learning / AI).

## Contents
- **practical_03_dfs.py**: Depth First Search (DFS)
- **practical_05_a_star.py**: A* Search Algorithm
- **practical_09_train_test_split.py**: Train Test Split
- **practical_11_decision_tree.py**: Decision Tree Classifier
- **practical_12_kmeans.py**: K-Means Clustering
- **practical_14_simple_linear_regression.py**: Simple Linear Regression

## Requirements
```bash
pip install scikit-learn pandas matplotlib numpy
```
